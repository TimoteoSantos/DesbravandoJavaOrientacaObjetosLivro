## 📘 Sobre o Projeto

Este repositório contém exercícios propostos pelo livro **Desbravando Java e Orientação a Objetos**, no qual estudei os fundamentos da programação orientada a objetos utilizando a linguagem Java.

Ao longo dos exercícios, são abordados conceitos como:
- Classes e objetos  
- Atributos e métodos  
- Encapsulamento  
- Abstração  
- Polimorfismo  
- Interfaces  
- Métodos construtores  
- Métodos estáticos  
- Entre outros conceitos fundamentais de POO  

O livro segue uma linha de raciocínio progressiva, permitindo escrever e refatorar o código de forma consciente, facilitando o entendimento das diferentes abordagens de implementação.  
Além disso, o projeto também explora algumas melhorias e recursos introduzidos a partir do **Java 8**.
