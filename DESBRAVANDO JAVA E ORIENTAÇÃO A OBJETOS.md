Exercícios propostos pelo livro Desbravando Java e Orientação a Objetos, no qual tive o prazer de estudar os fundamentos da orientação a objetos. 
Ao longo do conteúdo, foram abordados conceitos como classes e objetos, atributos e métodos, encapsulamento, abstração, polimorfismo, interfaces, métodos construtores, métodos estáticos, entre outros.

O livro segue uma linha de raciocínio progressiva, permitindo escrever e refatorar o código de forma consciente, facilitando o entendimento das diferentes maneiras de implementar soluções.

Além disso, são introduzidas algumas melhorias e recursos trazidos a partir do Java 8.
